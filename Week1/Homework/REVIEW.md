# 1주차 자기소개 페이지

HTML과 CSS로 작성한 자기소개 페이지입니다. `index.html`을 열거나, 이 폴더에서 아래 명령으로 로컬 미리보기를 실행할 수 있습니다.

```sh
python -m http.server 4175 --bind 127.0.0.1
```

브라우저 주소: `http://127.0.0.1:4175`

## 코드 리뷰 반영

- 페이지 제목을 `h1`으로 변경하고 기본 여백을 정리했습니다.
- 목차를 `ul`과 `li`로 묶었습니다. 각 `a`의 기존 섹션 링크는 유지했습니다.
- 이미지 20개에 실제 내용을 설명하는 `alt`를 추가했습니다.
- 첫 포토 덤프의 이미지 6개는 지연 로딩을 해제하고, 사진첩과 관심사 이미지 14개는 `loading="lazy"`를 사용합니다.
- 관심사 카드의 열 수를 미디어 쿼리로 지정했습니다.
- 작은 화면에서는 목차를 본문 위로 배치하고, 목차와 헤더가 섹션 제목을 가리지 않도록 스크롤 여백을 조정했습니다.
- 웹토리 문장 앞뒤의 도토리를 `::before`와 `::after`로 추가했습니다.
- 남아 있던 직접 색상값을 `:root` 변수로 모으고, 버튼 마크업의 들여쓰기를 정리했습니다.

## 반응형 구간

| 화면 너비 | 관심사 카드 열 수 |
| --- | --- |
| 320~767px | 2열 |
| 768~1023px | 3열 |
| 1024~1279px | 4열 |
| 1280px 이상 | 5열 |

카드 내용이 지나치게 좁아지지 않도록 768px 미만에서는 목차를 가로로 배치해 본문 너비를 확보합니다. 헤더의 좌·중·우는 모든 구간에서 동일한 너비의 3열입니다.

## clamp 값의 기준

`clamp(최솟값, 유동값, 최댓값)`은 작은 화면에서 필요한 최소 크기를 확보하고, 넓은 화면에서는 최대 크기를 넘지 않도록 사용했습니다.

- 헤더 높이 `clamp(64px, 5vw + 40px, 76px)`: 64px의 최소 높이와 76px의 최대 높이 사이에서 화면 너비에 따라 달라집니다. 화면 너비가 480px 이하이면 64px, 720px 이상이면 76px입니다.
- 헤더 왼쪽 여백 `clamp(12px, 3vw, 44px)`: 좁은 화면의 가장자리 여백은 12px 이상, 넓은 화면에서는 44px 이하로 제한합니다.
- 카드 간격 `clamp(8px, 1.2vw, 14px)`: 카드 사이 간격을 8~14px 안에서 조절합니다. 카드의 열 수는 이 간격과 별개로 위 표의 미디어 쿼리가 결정합니다.

이 값들은 CSS에 사용한 화면 배치 기준이며, 기기마다 고정된 정답값을 의미하지는 않습니다.

## 확인한 동작

- 320, 375, 767, 768, 1023, 1024, 1279, 1280, 1440, 1920px에서 카드 열 수와 페이지의 가로 넘침을 확인했습니다.
- 동일한 화면들에서 헤더의 세 영역 너비, `h1` 한 개, 이미지 20개의 `alt`, 포토 덤프 이미지 로딩과 앞뒤 도토리 표시를 확인했습니다.
- 320px와 1440px에서 목차 네 항목의 이동 및 섹션 제목이 고정 영역에 가리지 않는 것을 확인했습니다.
- 375px에서 사진첩의 가로 이동, `scroll-snap-type: x mandatory`와 각 사진의 `scroll-snap-align: start`를 확인했습니다.
